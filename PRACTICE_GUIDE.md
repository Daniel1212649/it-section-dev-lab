# Как проходить практику

Этот репозиторий используется как источник заданий. Ваши решения и история
обучения хранятся в вашем Fork.

## 1. Создайте Fork

На странице репозитория нажмите `Fork`. GitHub создаст вашу копию проекта.

## 2. Клонируйте свой Fork

```bash
git clone https://github.com/<ваш-username>/it-section-dev-lab.git
cd it-section-dev-lab
```

## 3. Создайте ветку

Примеры имен:

```text
practice/01-linux
practice/02-git-basics
practice/03-api-contract
```

```bash
git switch -c practice/01-linux
```

Не выполняйте задания напрямую в `main`.

## 4. Выполните задание

Задание находится в директории темы. Во время работы фиксируйте:

- использованные команды;
- промежуточные результаты;
- ошибки и способы исправления;
- итоговые выводы.

Не переносите готовое решение механически. Ценность практики находится в вашем
процессе и истории коммитов.

## 5. Делайте понятные коммиты

```text
docs: add Linux command notes
feat: add API contract example
test: add storage tests
fix: correct URL validation
```

Один коммит должен описывать одно логическое изменение.

## 6. Сохраните решение

```bash
git push -u origin practice/01-linux
```

Решение остается в вашем Fork. Pull Request в основной репозиторий для личного
решения открывать не нужно.

## 7. Поделитесь результатом

Опубликуйте ссылку на ветку или репозиторий в Telegram или GitHub Discussions.
Добавьте короткое описание:

```text
Задание:
Ссылка на решение:
Что получилось:
Что было сложно:
Что понял после практики:
```

## Как получить новые задания

Периодически синхронизируйте Fork через кнопку `Sync fork` на GitHub либо
добавьте исходный репозиторий как `upstream`.
