# IT Section Developer Growth Lab

Публичный репозиторий с практическими заданиями по разработке.

Здесь теория закрепляется руками: через отдельные ветки, небольшие коммиты,
эксперименты и собственные выводы.

## Что изучаем

- Linux и инструменты разработчика
- Git и командная работа
- API и взаимодействие сервисов
- TCP, UDP, HTTP и TLS
- REST, gRPC и WebSocket
- базы данных и транзакции
- тестирование, Docker и CI/CD
- брокеры сообщений, кеширование и observability
- Kubernetes и распределенные системы

Актуальное состояние тем находится в [ROADMAP.md](ROADMAP.md).

## Как начать практику

1. Сделайте Fork этого репозитория (желательно чтобы название совпадало с вашим никнейм на Git).
2. Клонируйте свой Fork.
3. Выберите задание в соответствующей директории.
4. Создайте отдельную ветку `practice/<номер>-<тема>`.
5. Выполните задание и сохраните процесс небольшими коммитами.
6. Оставьте решение в своем Fork.
7. Поделитесь ссылкой на решение в Telegram или GitHub Discussions.

Подробная инструкция: [PRACTICE_GUIDE.md](PRACTICE_GUIDE.md).

> Личные решения заданий не нужно отправлять Pull Request в основной
> репозиторий. Каждый участник хранит собственную историю практики в своем Fork.

## Когда нужен Pull Request

Pull Request в основной репозиторий приветствуется, если вы:

- исправляете ошибку в задании;
- улучшаете документацию;
- добавляете тесты;
- предлагаете новое практическое задание;
- исправляете или улучшаете общий код проекта.

Перед участием прочитайте [CONTRIBUTING.md](CONTRIBUTING.md).
