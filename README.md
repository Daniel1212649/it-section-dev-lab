# Практические задания по работе с Linux

## Главная мысль

Linux-база нужна не ради команд. Она нужна, чтобы быстро ориентироваться в проекте, логах, конфигах, контейнерах и серверах.

## Что нужно запомнить

| Команда | Назначение |
|---------|------------|
| `pwd` | где я |
| `ls -la` | что здесь |
| `cd` | перейти |
| `mkdir` | создать папку |
| `touch` | создать файл |
| `cat` | вывести маленький файл |
| `less` | читать большой файл |
| `head` | начало файла |
| `tail` | конец файла |
| `tail -f` | live-логи |
| `grep` | найти текст |
| `find` | найти файл |
| `wc` | посчитать строки |
| `sort` | отсортировать |
| `uniq` | убрать дубли |
| `nano` | быстро отредактировать |

## Практика

### Задание 1: создать структуру и разобраться с навигацией

Создай учебную структуру:
linux-practice/
app/
main.py
config.env
logs/
app.log
data/
names.txt

Что нужно попробовать:
mkdir
mkdir -p
cd
pwd
ls
ls -la
touch
find

Что проверить:

1. Перейди в папку linux-practice.
2. Покажи текущий путь.
3. Покажи все файлы и папки.
4. Покажи скрытые файлы.
5. Найди все обычные файлы через find.
6. Найди только директории через find.

Цель задания: научиться быстро понимать, где ты находишься и что лежит внутри проекта.

### Задание 2: работа с логами и текстом

Создай файл logs/app.log и добавь туда несколько строк:

INFO app started

DEBUG loading config

ERROR database connection failed

INFO retrying

ERROR timeout

Создай файл data/names.txt:
alice
bob
alice
daniel
bob

Что нужно попробовать:
cat, less, head, tail, tail -f, grep, grep -i, grep -n, grep -v, wc -l, sort, uniq, sort | uniq, sort | uniq -c, nano

Что проверить:

1. Выведи весь лог.
2. Покажи первые 2 строки.
3. Покажи последние 2 строки.
4. Найди все ERROR.
5. Найди ERROR с номерами строк.
6. Посчитай количество ERROR.
7. Исключи DEBUG из вывода.
8. Отсортируй names.txt.
9. Убери дубли из names.txt.
10. Посчитай, сколько раз встречается каждое имя.

Цель задания: научиться читать файлы, искать ошибки, фильтровать шум и быстро получать полезную информацию из текста.
