# Практика 01: Linux и работа с файлами

## Цель

Научиться ориентироваться в файловой системе, читать файлы, искать ошибки и
обрабатывать текст стандартными командами Linux.

## Задание 1. Структура и навигация

В `solutions/01-linux` создайте структуру:

```text
linux-practice/
├── app/
│   ├── main.py
│   └── config.env
├── data/
│   └── names.txt
└── logs/
    └── app.log
```

Используйте `mkdir`, `mkdir -p`, `cd`, `pwd`, `ls`, `ls -la`, `touch` и
`find`.

Проверьте:

1. текущий путь;
2. обычные и скрытые файлы;
3. поиск только файлов;
4. поиск только директорий.

## Задание 2. Логи и текст

Добавьте в `logs/app.log`:

```text
INFO app started
DEBUG loading config
ERROR database connection failed
INFO retrying
ERROR timeout
```

Добавьте в `data/names.txt`:

```text
alice
bob
alice
daniel
bob
```

Используйте `cat`, `less`, `head`, `tail`, `tail -f`, `grep`, `wc`, `sort`,
`uniq` и `nano`.

Получите:

1. первые и последние две строки лога;
2. все строки с `ERROR` и номера этих строк;
3. количество ошибок;
4. лог без строк `DEBUG`;
5. отсортированный список имён без дублей;
6. количество повторений каждого имени.

## Результат

В `solutions/01-linux/README.md` сохраните использованные команды и коротко
опишите, что делает каждая из них. Файлы должны содержать ровно указанные строки
без пустых строк между ними.
