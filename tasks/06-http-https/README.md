# Практика 06: вопросы про HTTP и HTTPS

## Цель

Проверить понимание HTTP как правил общения клиента и сервера, а HTTPS - как
защищенного HTTP поверх TLS.

## Задание. Вопросы на понимание

Создайте `solutions/06-http-https/http-https-questions.md` и ответьте на 10
вопросов. Для каждого ответа достаточно 2-4 предложений.

1. Почему HTTP находится выше TCP в цепочке взаимодействия?
2. Из каких основных частей состоит HTTP request?
3. Что показывают HTTP methods? Приведите примеры `GET`, `POST`, `PATCH` и
   `DELETE`.
4. Зачем нужны headers и какие проблемы могут возникнуть из-за неверных
   headers?
5. Когда в HTTP request обычно появляется body?
6. Из каких основных частей состоит HTTP response?
7. Что означают группы status codes `2xx`, `3xx`, `4xx` и `5xx`?
8. Почему не стоит возвращать `200 OK`, если на самом деле произошла ошибка?
9. Что такое CORS и почему ошибка CORS чаще видна именно в браузере?
10. Чем HTTPS отличается от HTTP и какую роль играет TLS?

## Критерии готовности

- ответы написаны своими словами;
- есть пример HTTP request или endpoint;
- объяснены status codes и headers;
- отдельно раскрыты CORS, HTTPS и TLS;
- файл оформлен в Markdown.
