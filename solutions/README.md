# Решения

Эта директория предназначена для личных решений в Fork участника.

Рекомендуемая структура:

```text

├── 01-linux/
├── 02-git/
├── 03-api/
├── 04-client-server/
├── 05-tcp-udp/
├── 06-http-https/
└── 07-rest/
```

В основном репозитории готовые решения не публикуются: здесь остаётся только
эта инструкция.
